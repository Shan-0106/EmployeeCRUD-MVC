# Employee CRUD using ASP.NET MVC + Entity Framework

This project is a simple CRUD application for managing employees.

## Features
- Add Employee
- Edit Employee
- Delete Employee
- View Employee List
- Search Employee by Name

## Tech Stack
- ASP.NET MVC 5
- Entity Framework 6
- SQL Server
- Bootstrap
